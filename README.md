# Billing Application - .NET Console System 💳📄

A billing management system developed in C# utilizing .NET and Dapper for database interactions.

## 🚀 About the Project
This application provides a console interface for managing the complete billing cycle, including:
- Creating and detailing invoices.
- Managing product inventory.
- Customer management.

## 🛠️ Technologies Used
- **Language**: C#
- **Framework**: .NET 8.0
- **Data Access**: Dapper (Micro-ORM)
- **Database**: SQL Server

## ⚙️ How to Run
1. **Restore Dependencies**:
   ```powershell
   dotnet restore
   ```
2. **Run Application**:
   ```powershell
   dotnet run --project billingApplication.csproj
   ```
